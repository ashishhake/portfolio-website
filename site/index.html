Phase 1
Static Site with Automated CI/CD Pipeline
Deploy a portfolio/blog site using S3 + CloudFront with GitHub Actions for auto-deployment on every push.
S3 CloudFront Route 53 ACM GitHub Actions
⏱ 1–2 weeks Details
What You'll Build
  • S3 bucket configured as static website host with proper bucket policies
  • CloudFront distribution with HTTPS via ACM certificate
  • Custom domain with Route 53 hosted zone + DNS records
  • GitHub Actions workflow: build → test → invalidate cache → deploy
Why Hiring Managers Love This
  • Shows you know the full web hosting stack, not just "upload to S3"
  • CI/CD is table stakes for every DevOps role in 2026
  • Demonstrates cost-awareness (S3+CF is near-zero cost)
📄 Resume Bullet
Architected and deployed a globally distributed static site using AWS S3 + CloudFront with automated CI/CD via GitHub Actions, reducing deployment time by 90% and achieving 99.9% uptime with SSL/TLS termination via ACM.

⏱ 3–4 weeks Details
